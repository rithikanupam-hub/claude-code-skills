# Claude Code skills

112 skills for Claude Code: video and motion, voice, design and UI, research, automation and development. Each folder in `skills/` is one complete skill: a `SKILL.md` plus its scripts, references and assets.

## Install

Copy or symlink a skill folder into `~/.claude/skills/`:

```bash
git clone https://github.com/rithikanupam-hub/claude-code-skills.git
ln -s "$PWD/claude-code-skills/skills/voice-modulation" ~/.claude/skills/voice-modulation
```

Some skills need their own dependencies (`pip install -r requirements.txt` or `npm install` inside the folder). Skills that call paid APIs (ElevenLabs, Higgsfield, Gemini, Fish Audio) need your own API key.

## Licences

Several skills are by other authors and keep their own `LICENSE` file inside their folder. Check it before reusing one.
