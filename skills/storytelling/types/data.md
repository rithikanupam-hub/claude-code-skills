# Type: Data story

**Job:** one real number, made human: what it means for one person. The data is the hero, and the viewer remembers one number and one feeling.
**Simulated viewer:** a parent who loves football and isn't a data person.

## Spine
- **The number** (traceable to a file and a script).
- **The person** it belongs to.
- **The contrast** that makes it surprising (touched the ball only 20 times, but ran the most).
- **What it means for them** (what to change next Sunday).

## Shape
Default frame: claim → proof → meaning (evidence board), 15–40 s. Paths, heatmaps and moments are drawn from the real data, never invented shapes. Scroll-driven web versions go to `scroll-motion-web`.

## Ending and selling
None. The meaning line closes it. A brand mark is fine. No rankings of kids against each other.

## Story check: extra items
- Every number is recounted from the raw file with the script, and the file path is written next to it in `script.md`.
- Labels match the data (say "conduzioni", not "dribbling", when the data has no dribble label).
- Screen text reads in 1 s; the voice may use idiom.
